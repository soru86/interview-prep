# Learning Code Labs: Python Programs

This repository contains 98 standard Python programming examples based on the list from [Programiz](https://www.programiz.com/python-programming/examples).

These examples cover a wide variety of foundational programming concepts, including:
- Basic Input/Output and Arithmetic
- Decision Making and Loops
- Functions and Recursion
- File Handling
- String and List Operations
- Data Structures (Dictionaries, Sets)
- Object-Oriented Programming basics (Classes, Inheritance)
- Exception Handling

## Structure

Each program is implemented in a separate, runnable Python file named in the format `XX_program_name.py`.
The files follow Python best practices:
- Type hinting is heavily utilized.
- All files have module-level docstrings explaining their purpose.
- Each program can be executed standalone using the `if __name__ == "__main__":` block.
- Standard libraries are prioritized over third-party dependencies.

## Usage

You can run any of the examples directly from your terminal using Python 3:

```bash
python 01_hello_world.py
python 51_flatten_nested_list.py
python 98_convert_bytes_to_string.py
```
